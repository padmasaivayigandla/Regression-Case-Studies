# Regression-Case-Studies

Project Overview:

This repository contains a collection of regression-based case studies implemented using Python to solve real-world business problems.
The projects focus on predictive modeling, feature selection, and model evaluation using linear and logistic regression techniques.

Each notebook follows a structured data science workflow including data understanding, preprocessing, modeling, and interpretation of results.

Case Studies Included
=====================
1. **Advertising Sales Prediction (Simple Linear Regression)**

Predicts sales based on advertising spend

Demonstrates:

Linear relationship analysis

Model interpretation

Residual analysis

2️. **Housing Price Prediction (Multiple Linear Regression)**

Predicts house prices using multiple predictors

Covers:

Multicollinearity

Feature scaling

Model diagnostics

3️. **Housing Case Study using RFE**

Applies Recursive Feature Elimination (RFE)

Focuses on:

Feature selection

Model optimization

Interpretability

4️. **Telecom Customer Churn (Logistic Regression)**

Predicts customer churn probability

Includes:

Categorical encoding

Logistic regression modeling

Confusion matrix & ROC analysis
